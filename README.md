# Bastide Cards

A collection of custom dashboard cards for [Home Assistant](https://www.home-assistant.io/), installable through [HACS](https://hacs.xyz/).

> **Work in progress** — the first card is being built. Nothing to install yet.

## Planned cards

| Card | Type | Description |
| --- | --- | --- |
| Heating | `custom:bastide-heating-card` | See at a glance which heat source is running and why. |

## Installation (once the first release is out)

1. In HACS, open the menu (⋮) → **Custom repositories**.
2. Add `https://github.com/Bolero27/bastide-cards` with the type **Dashboard**.
3. Search for **Bastide Cards** in HACS and install it.
4. Reload your browser.

## Language

Cards follow your Home Assistant language. English and French are supported.
